# Version Information

## Where to find version in the repository

Version information for aap-gateway is stored in `aap-gateway/VERSION`; changing the text in this file will change the version string in the application.

If no VERSION file is present, the version will fallback to one generated by setuptools_scm.

Version numbers follow the [python versioning specification](https://packaging.python.org/en/latest/specifications/version-specifiers/#version-specifiers)

## Where to access the version in the REST API

To read the version of aap-gateway within the application, GET `/api/gateway/ping`; it should be the value of the `'version'` key in the response data.

This method should only yield the `x.y` version information for the application.
